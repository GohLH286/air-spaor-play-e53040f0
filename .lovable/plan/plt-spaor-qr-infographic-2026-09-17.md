# PLT SPAOR QR Infographic

## Build
- Add direct section links so a scanned QR code opens Scan, Plan, Action, Observe, or Review immediately.
- Create a one-page, print-ready infographic using the project's dark-blue futuristic palette and five SPAOR colours.
- Give each stage a short visual summary and a tested QR code pointing to the published lesson section.

## Deliverables
- Downloadable PDF infographic.
- Visual-design philosophy file used to guide the artwork.

## Technical details
- Section links will use a `stage` URL parameter while preserving normal navigation.
- QR codes will use the stable published app URL and high-error-correction encoding.
- The PDF will be rendered and visually inspected for legibility, spacing, clipping, and QR scanability before delivery.
